# Memulai

Mari kita mulai perjalanan Anda bersama Rust! Ada banyak hal yang perlu dipelajari, tetapi setiap perjalanan selalu dimulai dari suatu tempat. Dalam bab ini, kita akan membahas:

- Menginstal Rust di Linux, macOS, dan Windows
- Menulis program yang mencetak `Hello, world!`
- Menggunakan `cargo`, package manager dan build system milik Rust
